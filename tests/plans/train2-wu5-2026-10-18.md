## Known gaps (deliberate)

- No E2E/SPA tests here: the screens half of WU-5 belongs to the Train 2
  screens developer; this pack is backend behaviour through real entry points.
- Observation channel: every injection assertion reads the value's LENGTH
  computed inside the real child (`${#WEATHER_TOKEN}`), never a raw print —
  BDD-7.3 makes a raw exact-value print masked in returned output, so a raw
  print would make the scoping assertions (7.2/7.5/7.12) unfalsifiable. The
  spec itself uses the length read for BDD-7.1. SPEC GAP flagged for the
  chief: BDD-7.5 ("the value is B" — visible) vs BDD-7.3 (a bare owner print
  is masked) pull the masking semantics in opposite directions for the SAME
  observation; the pack resolves it in favour of the length channel, which
  satisfies both readings. If the founder intends owner prints to be visible,
  only #4 (masking) and #1 (length) need touching — no scoping test changes.
- BDD-6.23's approval-driven rollback leg (Omnipus rolls back to v1 through
  its Ask card) rides the approval machinery the founder assigned to Train 3
  (plan §11, 2026-10-18: approvals.go, ws_tool_approval.go,
  policy_approver.go are Train-3 files). This pack pins the surface fact
  (catalog entry) and the ordinary-agent refusal; Train 3's pack drives the
  approval round-trip.
- BDD-7.4's "no request_secret" half is owned by the existing worker-tier
  denial seeding (`pkg/coreagent/seed.go::workerTierDeniedTools` already
  names request_secret); this pack pins the env half (no private variable in
  the recorded RunOptions.Env) with a PATH control proving the slice is real.
- Removal/removal-refusal flows (#12's "listed and removable") are asserted
  here only as far as K6 listing state; the removal behaviour itself is WU-6
  (US-15, tests 48/49/95) and gets its own pack.
- BDD-7.12's power for the "off" row is jointly carried with test #1: unset is
  vacuous until the owner-injection positive exists. The pair (1 + 10) is what
  makes the flag gate falsifiable; stated here so CHECK reads them together.
- Per-child negative-case ratio: the pack's refusal/absence oracles (grammar
  table 14 refusal rows, scoping exclusions, 401/404/422, never-values,
  never-gateway) are ≥30% of the assertions.
