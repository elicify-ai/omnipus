# Code intelligence

This project uses **GitNexus**, not graphify. `graphify` is retired — there is no
`graphify-out/` here, and `/graphify` is not a workflow for this repo.

For codebase questions use the GitNexus MCP tools (`query`, `context`, `impact`, `trace`,
`explain`), falling back to Read/Grep when the graph does not cover a file. See the
"Code intelligence: GitNexus" and "GitNexus — Code Intelligence" sections in the root
`CLAUDE.md`.
