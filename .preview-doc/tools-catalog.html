Builtin Tool Catalog v0.3 to-be · domain-categorized

The proposed v0.3 end-state. 79 tools across 16 domain categories — no system dumping ground. Names are verb-first snake_case (no dots) per OpenAI/Anthropic/MCP; the system_ prefix is dropped (redundant with the privileged access badge); redundant duplicates + dead-end/no-UI tools retired; task-system refactor applied. See docs/internal/design/tasks-system-refactor-2026-06.md.

79 tools · 16 categories no system category 24 open · 54 privileged · 1 gated
How to read this

Three dimensions per tool

Access — who can call it (the live enforcement axis; today core/general, fail-closed — see ADR-018. privileged replaces the old system prefix.)
open any agent privileged core agents default; a custom agent needs an explicit policy allow (admin / cross-workspace) gated needs an extra operator flag on top of policy (e.g. browser_evaluate_enabled)
Manifest — token strategy (proposed: compressed-manifest model — every tool's name+purpose always visible; full schemas fetched on demand)
full always loaded — high-frequency; full schema in context compressed manifest entry only; full schema fetched on demand (saves ~7–11k tokens/turn)
Risk — security / destructiveness
🟢 read read-only / safe 🟡 write mutating, recoverable 🔴 delete destructive / irreversible ⚡ exec arbitrary code / JS 🔐 admin privileged platform config

Counts: 31 read · 35 write · 7 delete · 4 admin · 2 exec.   Manifest: 13 full · 66 compressed.   The 7 🔴 delete + 4 🔐 admin + 2 ⚡ exec tools warrant the most care (re-auth, admin-ask fence, audit). MCP-server and skill tools layer on top at runtime; workspace.shell/workspace.shell_bg are omitted by design (experimental, config-gated).

No more system category — tools live in domain categories (v0.3)

The system_ prefix is gone: it was a 40-tool dumping ground and redundant with the privileged access badge (which already says "admin"). Every tool now lives in its proper domain category — agents, workspaces, channels, providers, mcp, skills, platform — with the prefix dropped (system_create_agent → create_agent).

Redundant tools collapsed (same general-vs-system duplication as tasks): system.agent.list→merged into list_agents; system.skill.search→merged into find_skills; system.skill.install→merged into install_skill. Also retired: cron, task_add_dependency, task_add_todo, pins (no UI); added set_todos. See docs/internal/design/tasks-system-refactor-2026-06.md.
