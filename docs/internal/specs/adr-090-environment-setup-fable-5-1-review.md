## Founder dispositions — 2026-09-18 (after this review)

The review above is preserved as evidence of the reviewed draft. These subsequent decisions update the ADR and specifications; they are not implementation or test completion:

- **GS-03:** Existing unattended/scheduled Ask auto-denial is intentional. Remove the promised pending approval; no new queue or workflow.
- **GS-04 / GS-19:** Remove execution-dependent custom defaults. Custom agents inherit global Ask unless explicitly overridden. Both creation paths and the existing preview must reflect inheritance; no proposed-execution preview extension.
- **GS-06:** Admin has cross-workspace filesystem authority without membership. Ordinary callers require target authority; every job and its hooks stay confined to the explicitly selected destination.
- **GS-09:** Installation runs asynchronously using existing background sessions, returning session_id with poll/read/kill handling, bounded execution and truthful completion/partial-failure results. Session ownership, cancellation and interrupted-job behavior need acceptance coverage.

ES-BDD-08–11 cover these decisions. Their implementation and execution remain pending. Other review findings remain open for disposition; this amendment does not change the original REVISE verdict or claim a fresh independent review.
