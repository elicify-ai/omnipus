# Ingest response ownership

The answer or error from an authenticated encoder offer belongs to that original socket binding, offer ID, capture generation and target. Its deadline starts when the offer is received and remains active through final writer admission. Negotiation completion must not cancel the request before writing, and a replacement binding/frame/offer must invalidate a response waiting for the writer.

Tests will keep CaptureSession binding/offer admission real, substituting only the external relay negotiation. They will establish a valid response identity, then reject the old immutable tuple after a new offer, frame, binding, cancellation or stop. Gateway tests will retain the real WebSocket writer and stall its admission, proving that a retired or expired response cannot escape after the wait. Successful response delivery remains a positive control. Error responses use the same original source lifetime; no Background context revives canceled work.

The connection-wide terminal diagnostic is an explicit exception: invalid-offer and queue-overflow notices use the existing bounded writer on the same closing socket. This does not authorize an answer, ordinary offer error, or recapture after its original request retires.
