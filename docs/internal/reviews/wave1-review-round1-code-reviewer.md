## Cross-slice causal chains

1. **Known text-only model still receives image:** runtime candidate is `deepseek/deepseek-chat` -> C exact lookup misses bare `deepseek-chat` -> optimistic result says image-capable -> F does not consult C anyway -> provider receives image -> E broad residual-4xx fallback is required to recover. The proactive gate has failed before retry begins.
2. **Oversize image still becomes unavailable:** user source exceeds legacy 20 MB `max_media_size` or a tighter provider budget -> F returns before DecodeConfig/resize -> no JPEG ladder -> current resolver emits unavailable marker; later offload can preserve the turn but resize-to-fit never gets a chance.
3. **Integrity guarantee cannot reach decode:** B1 verifies SHA-256 into returned bytes -> F's guarded decoder accepts only a path and reopens it -> either Wave 3 bypasses B1 by using the path or duplicates DecodeConfig/decode around B1 bytes -> one of the two security invariants loses its single source of truth.
4. **New classifier error disappears at the SPA boundary:** provider body matches tool/schema phrase -> E emits `tool_args`/`schema` -> gateway stores it in generated `Code string` -> JSON is produced -> generated Zod enum rejects it because contracts were not changed.
5. **Relabel claim has no observable result:** residual 4xx with media -> E strips and retry succeeds -> loop writes `turnState.outcomeRelabel` -> no production reader exists -> no transcript/event/audit/metric contains the promised `media_unsupported` outcome.
