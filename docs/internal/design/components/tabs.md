# Tabs

Tabs is a public presentation primitive in the Omnipus design system. It preserves the existing Sovereign Deep appearance and consumes shared foundation tokens.

## Contract

- Variants: default.
- Sizes: default, dense.
- States: inactive, active, disabled, focus-visible.
- Public exports: Tabs, TabsList, TabsTrigger, TabsContent.
- Theme: dark.

The colocated stories cover every declared variant, size and state, plus dense and narrow-viewport presentations. The Activation story performs a real pointer activation, verifies the selected tab, and verifies that its associated panel is exposed. The manifest maps applicable unit, interaction, accessibility, keyboard, pointer, motion, forced-colour, root-size, zoom and reflow checks to executable evidence.
