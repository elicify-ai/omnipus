# Calendar

Calendar is the themed react-day-picker composite. It preserves DayPicker selection modes, controlled selection, disabled and outside days, locale behavior and grid keyboard operation while applying the dark design-system presentation. Weekday headers use the shared 12 px text floor. Outside-month days use the muted semantic text color without opacity, retaining their secondary affordance while meeting text-contrast requirements. In forced-colors mode, the selected day gains a two-pixel `Highlight` boundary and uses `CanvasText` against an explicit `Canvas` surface, so both selection and the day number remain visible independently of browser-native button remapping. Today's accent text also becomes `CanvasText`, preserving readable date text in forced-color palettes.

On coarse pointers, seven non-overlapping day targets require a 308 px grid: seven times the shared 44 px touch-target token. The Calendar bounds that intrinsically two-dimensional grid inside a local horizontal viewport, removes decorative padding when coarse-pointer space is constrained, and keeps its caption, navigation and dates in one minimum-width month box. Keyboard focus adjusts that local viewport by only the clipped edge distance before forwarding the caller's `onDayFocus`, so the first and last weekday remain reachable without scrolling the page. This applies the two-dimensional-content exception described by the [WCAG 2.2 reflow understanding document](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) to the Calendar's tabular week structure; the source does not explicitly name calendars.
