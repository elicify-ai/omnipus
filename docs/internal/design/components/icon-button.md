# Icon Button\n\nIcon Button is a public presentation primitive in the Omnipus design system. It preserves the existing Sovereign Deep appearance and consumes shared foundation tokens.\n\n## Contract\n\n- Variants: default, destructive, outline, secondary, ghost.\n- Sizes: sm, default, lg.\n- States: idle, pending, success, error, disabled, focus-visible.\n- Public exports: IconButton.\n- Theme: dark.\n\nThe colocated stories cover every declared variant, size and state, plus dense and narrow-viewport presentations. The manifest maps applicable unit, accessibility, keyboard, pointer, motion, forced-colour, root-size, zoom and reflow checks to executable evidence.\n

Every declared variant and action state has a story. Accessible naming is an exclusive `aria-label` or `aria-labelledby` type contract. Adjacent small controls use `--space-control-gap` (8px) for fine pointers. Under a coarse pointer they use `--space-4` (24px), the smallest available closed-scale spacing token that clears the 17px minimum gap needed by 27px controls at the 12px root size. The shared transparent hit-region treatment supplies fine/coarse target sizes without changing visible control geometry; callers must preserve this pointer-specific separation so adjacent hit regions do not overlap.
