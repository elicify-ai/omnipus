# Spinner

`Spinner` is the loading glyph (W2-1, R41), the same CircleNotch shape as Button's pending indicator. By default it is a `role="status"` region named by `label` ("Loading"); `decorative` hides it from assistive technology for use inside a control that already announces its busy state. Sizes: `sm` 16px (`--icon-size-medium`), `lg` 24px (`--icon-size-prominent`). It spins with `animate-spin` and stops under reduced motion.
