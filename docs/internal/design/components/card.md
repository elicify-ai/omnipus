# Card\n\nCard is a public presentation primitive in the Omnipus design system. It preserves the existing Sovereign Deep appearance and consumes shared foundation tokens.\n\n## Contract\n\n- Variants: default.\n- Sizes: default, dense.\n- States: default.\n- Public exports: Card, CardHeader, CardFooter, CardTitle, CardDescription, CardContent.\n- Theme: dark.\n\nThe colocated stories cover every declared variant, size and state, plus dense and narrow-viewport presentations. The manifest maps applicable unit, accessibility, keyboard, pointer, motion, forced-colour, root-size, zoom and reflow checks to executable evidence.\n
