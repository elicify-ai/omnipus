# Checkbox

Checkbox is the Radix-backed binary or indeterminate form primitive. It preserves controlled and uncontrolled checked state, native form identity, required and disabled semantics, keyboard operation, and a 44px coarse-pointer hit region without enlarging its visual mark. Disabled controls reject pointer and keyboard changes. The checkmark is decorative and hidden from assistive technology because the checkbox state carries the meaning.

In forced-colors mode, the checked control uses `Highlight` with a `HighlightText` indicator and boundary.
