Recommendation

Do both — lock all shell/panel header rows to the workspace top-bar height (44px / h-11, already the WCAG 2.5.8 floor used by the hamburger) and drop the header hairline borders in favour of a flat surface (content can still use spacing or a subtler surface step). Height alone leaves stacked borders; borders alone leave the step.

  • Token: introduce something like --spacing-chrome-header: 2.75rem /* 44px */ and a shared SheetHeader / chrome class.
  • Keep panel side borders and the sheet elevation shadow — only the header row border goes.
  • Exception: multi-line headers (title + description, e.g. ChannelConfig) should keep min-height 44px on the title row, not force single-line truncation of the description.
  • Sidebar brand: shrink logo 32→24 and padding so the brand row also hits 44px — otherwise the left rail still reads taller than the workspace bar.
