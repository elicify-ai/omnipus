Tools, Providers & Multimodal

Agents reach the world through tools — search, email, voice. The key pattern, already half-built: every external tool has a pluggable provider you pick in Settings. Web search and voice-in already work this way; we standardize it and add the missing pieces — email tools (read, search, send, reply) over a per-agent mailbox configured in Connectors, agent voices, and image generation. Provider-picker UI and chat mic in v0.1.0; TTS + image-gen in v0.2.

The headline: the per-tool provider pattern you want already exists — two interfaces (SearchProvider, Transcriber) with multiple implementations, config-selected. We standardize it and add two more (Synthesizer for TTS, ImageProvider) — plus the UI to drive them.
The model

One pattern: Tool → Provider → Config

Every external-service tool is a capability with a swappable backend. Pick the provider, drop in a key (encrypted store, behind the password re-type), optionally override per agent.

Capabilities & their providers

  • LLM — OpenRouter · OpenAI · Anthropic + failover
  • Web search — Brave · Tavily · Perplexity · SearXNG · GLM · Baidu exists
  • Voice-in (STT) — Groq/Whisper · ElevenLabs · audio-model exists
  • Email — IMAP/SMTP (pure-Go), one mailbox per agent, Connectors config v0.1.0 tool
  • Image — OpenAI · Replicate/Fal (Flux) · Stability · SD-local v0.2
  • Voice-out (TTS) — ElevenLabs · OpenAI · Cartesia · Piper-local v0.2

Two delivery modes — sovereignty

  • API (default) — HTTP to a hosted service; pure-Go, single binary, no CGo
  • Local sidecar (opt-in) — the established pattern (like Signal's signal-cli): run SearXNG · Piper · whisper.cpp · local SD over localhost
  • So a fully-local stack is possible — fits "no telemetry / The Sovereign Deep"
  • Global default per tool, with an optional per-agent override
The new capabilities

Voices, images & the three speech modes

🔊 One voice per agent flagship

A Synthesizer interface (mirrors the existing Transcriber) + a voice field on the agent persona (provider · voice-id · rate). Mia, Jim and your Assistant each sound distinct — agents become characters. Only Primary agents get voices.

🎨 Image generation

A generate_image tool + an ImageProvider. Result saved to the Workspace, rendered inline (display already exists), attachable to tasks / sent over channels. Per-agent tool policy. Edits/variations later.

🗣️ Speech — three distinct things

STT (voice-in, exists) + TTS (voice-out, new) compose into push-to-talk. Realtime (full-duplex, interruptible) is a separate provider type — native speech-to-speech or a streaming pipeline — heavier, later.

Vision (image input) already works — agents see images today. The new work is image output (generation) and voice output (TTS / agent voices).

Where it lands

Sequencing

v0.1.0 Surface what exists + email tool

  • Integrations provider-picker — surfaces the existing multi-provider search + voice-in (cheap, high-leverage)
  • Mic button in the composer — voice-in capture (the transcriber backend already exists)
  • Email tools — read_inbox · search_email · read_message · send_email · reply over a per-agent IMAP/SMTP mailbox account (configured in Connectors). Agent works inbox on heartbeat; un-handled mail → Board tasks. No inbox UI yet — the workspace Email tab lands in v0.2.

v0.2.0 Voices + images + email inbox UI

  • Email inbox UI — the workspace "Email" tab (inbox view + agent replies/actions; email-client surface)
  • One voice per agent — a Synthesizer interface + a voice field on Primary personas + chat playback
  • Image generation — a generate_image tool + ImageProvider (display is free)

v1.0.0 Realtime + sovereignty

  • Realtime voice — its own provider type (speech-to-speech)
  • Local sidecars (Piper · whisper.cpp · SD · SearXNG) — a fully-local stack
  • Per-agent provider overrides · voice notes over channels · image edits/variations
Effort is lower than it looks: search + voice-in + vision + image-render + the IMAP/SMTP transport are done. The genuinely new work in v0.1.0 is the email tool surface + wiring to heartbeat/Board, and the Integrations UI. TTS (agent voices) + image-gen are v0.2.
