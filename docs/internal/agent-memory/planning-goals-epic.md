Interview-locked decisions (2026-07-19, operator interview):

1. **Plan entity** — new first-class workspace-scoped `Plan` (goal, DoD, state machine draft→approved→running→done/failed, owner agent, plan_id FK on Task). **Milestones REMOVED entirely**, replaced by generic multi-`tags []string` on tasks (usable for milestones/releases/themes). Suggested migration: existing milestones auto-convert to tags.
2. **Judge = evidence ladder**, fail-closed: machine-checkable criteria (command + expected exit code, output stored as evidence) → prose criteria to LLM judge (per-criterion met/unmet + reason) → reasons fed forward as steering. ADR-043 marker remains only as the worker's claim.
3. **Coordinator = hybrid**: server-side plan engine dispatches ready tasks as DAG clears (extends AdvanceBlockedDependents + TaskExecutor); owner agent woken (async-notifier seam, `async_notifier.go:292`) only at decision points (attempts exhausted, plan judge failed, plan complete → synthesis).
4. **DoD policy tiered**: agent tool calls (create_task etc.) MUST carry ≥1 acceptance criterion (strict, rejected otherwise); human/UI creation soft (judge falls back to prompt-as-criterion).
5. **System Agents category** (revive `system` type): seeded, locked, visible in Agents screen "System" section, editable model + rubric prompt. **AMENDED (grill r1 + operator, 2026-07-19): this epic ships category + Judge ONLY.** The Summarizer premise was false — `forceCompression` is deleted (windowTrim/ADR-028 evicts with zero LLM calls; `summarizeSession` is legacy reference-only). Standing ADR rule: future out-of-turn LLM actions (scheduled retrospectives, dreaming mode) must run as System Agents; Memory System Agent lands with the first such feature (v0.3). Also: System Agents are NOT privileged — `IsPrivilegedAgent` narrowed to `core` only (SEC-26 rate limits/cost caps apply to Judge); excluded from default-agent fallback, routing bindings, delegation pickers, team rosters.
6. **/goal + /loop as separate commands** (loop=time-driven, goal=proof-driven). /loop both modes: interval (cron `every` + continue-session) and self-paced (agent picks next delay + reason, one-shot `at` jobs). /loop bare=status, /loop stop.
7. **Budgets: NO token/money brakes** (operator explicit). Count + calendar only, all configurable at every level (global→workspace→plan→task→goal): task 3 attempts → wake owner; /goal 20 rounds; /loop 100 runs; 7-day idle expiry. Codex-style graceful wind-down on brake fire (finish step + handover summary). Token spend visible in status, never enforcing.
8. **Goal-clear affordance at every level**: Clear/Stop button on task + plan cards, `/goal clear` + `/loop stop` in chat.
