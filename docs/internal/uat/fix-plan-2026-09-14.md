# Fix plan for the 2026-09-13 UAT findings

Source: `/Users/danielpiatkowski/AI-Agent-Workspace/omnipus/uat/evidence/2026-09-13/DEFECTS.md` (138 defects) and `UAT-REPORT-2026-09-13.md`.
Base branch: `integrate/library-improvements-v0.1.1`. Out of scope by founder ruling: the CLI Obsidian import and CLI/gateway locking (D-03, D-79, D-83, D-88). Everything else is in scope, S4 included.

## Shape of the campaign

1. **Five workstreams in parallel**, one agent each, each in its own git worktree and branch `fix/<ws>` cut from the base branch. File ownership is disjoint (table below); a workstream that must touch another's file coordinates through the orchestrator instead of editing it.
2. **Merge** in the order W1, W2, W5, W3, W4 (Go-heavy first), regenerate contracts once after the last merge, full CI on `ci-omnipus-3`.
3. **Two independent reviews in parallel** on the merged diff: `/code-review` at high effort inside Claude Code, and Codex CLI (`codex exec`) with a critical-review brief. Findings from both are fanned out to fix agents (one per finding cluster), then CI again.
4. **UAT re-run** of every row that failed, was blocked, or was confirmed as a defect, by self-validating Sonnet tester agents using the same lane definitions (`uat-browser-*`) and the same evidence discipline; each agent validates its own PASS against an oracle before reporting.

## Definition of done, per workstream

- Every assigned defect is either fixed with a regression test that fails on the old code, or listed in `FIX-REPORT-<ws>.md` as not fixed with the exact reason (design decision needed, blocked, disproved). No silent skips.
- S1/S2 fixes carry a mutation check (revert the fix, the test fails, restore byte-identical).
- Scoped tests green for touched packages; `gofmt -l` empty; `golangci-lint` clean on touched Go packages; `npm run typecheck` and `npx vitest run` clean when TS changed; contract changes go through `contracts/` + `scripts/gen-contracts.sh` (Constraint #8).
- One commit per defect cluster, authored as the human, no agent trailers, pushed to `origin fix/<ws>`.
- Report at `/Users/danielpiatkowski/AI-Agent-Workspace/omnipus/uat/evidence/2026-09-13/FIX-REPORT-<ws>.md`: defect id → commit → test name → verification → status.
