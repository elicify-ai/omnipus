## Corrections verified REAL in r2 (kept so r3 doesn't re-litigate)

Four tool-schema line citations exact; both parsers read only `m["check"]`; the all-check gate runs on the un-normalized slice after the parser on the two task tools; `JudgeDefaultRubric` already prose-first and `buildJudgeUserContent` is the machine-first surface (header string verified); current section order machine→diff→window→criteria→claim; `evidence_quote` instructed by the rubric but discarded by the parser; `SeedDefaults` copies missing embedded skill dirs; today's `/goal` compiler is a deterministic marker parser; `MinCount`/`MaxCount` pointer semantics; persisted criteria always carry explicit kinds (both stores); PlanSupervisor exactly-one-skill tests exist (`plan_supervisor_seed_test.go:216`, `:232`).

## CRITICAL

- **CRIT-1 — D4a's "echo-and-confirm is unchanged as the commitment point" is false for fresh `/goal set`.** The confirm/amendment branch is entered only when a goal is already active (`goal_loop.go:114-116`); a fresh set compiles, activates via unconditional `SetMeta` (`:152-168`), and continues into round 1 in the same turn (`:184-185`, "the /goal command IS the chat confirmation"). D4a's cost bound and its nondeterminism mitigation both rested on a confirm step that doesn't exist on that path; `confirmPendingGoal` (`:239+`) is reachable only via amendment.
- **CRIT-2 — "the card consumes the existing `Goal.criteria` REST surface" — no such surface.** `Goal.yaml` is components-only for codegen (`openapi.yaml:851-852`); no path returns a Goal. `GoalStatusFrame` carries no criteria (`GoalStatusFrame.yaml:18-27`); `GoalThreadTailCards.tsx:44-49` never passes `literalCommands`. The gap is the current state; a new contract surface is a prerequisite of D5.2 with its own rollout slot.
- **CRIT-3 — the FR-113 reconciliation rests on dead code.** `formatGoalEcho` (`goal_compile.go:470`) has exactly one caller: its own test. The fresh-set path emits only a status frame. The FR-113 itemization guarantee is currently delivered by no surface; r2 disposed of r1 MAJ-010 by designating an unreached function as authoritative.
- **CRIT-4 — the allowlist append is a no-op on every existing install.** `SeedConfig`'s core-agent skills application is double-gated `isFreshInstall && len(a.Skills)==0` (`core.go:1812-1817`) with an explicit do-not-restore comment (`:1800-1811`). Post-upgrade: skill on disk, every core agent's default-DENY allowlist excludes it, every load fails. "No migration needed" tells the implementer not to look. Must specify a migration and reconcile with ADR-072 D5.1's prohibition.
- **CRIT-5 — the seam correction is wrong for PlanSupervisor.** `coreAgentSkills` has no `IDPlanSupervisor` case; its allowlist comes from `systemAgentSkills` (`core.go:1324-1336`), seeded `:1959`/`:1987` and hard re-enforced every boot with an exact-equality overwrite (`:2068-2071`) — the one agent where the grant propagates automatically. The `core.go:1401-1402` no-drift invariant and the three `ReEnforced` tamper cases (`plan_supervisor_seed_test.go:232-257`) must be addressed by the amendment.

## MAJOR

- **MAJ-1** — the D2-rule-5 gate exists on two of the four widened tools only; `create_plan` (`plan.go:280`) and `plan_correct` (`plan_correct.go:660` — agent-assigned tail members, `:684-696`) have none. Stop implying the gate question is settled; state coverage and disposition.
- **MAJ-2** — the gate has never existed at the REST layer (`bashPolicyChecker` wired only at the tool layer; `rest_tasks.go:1164-1165` applies none). D2 changes what reaches the pre-existing hole (kind can now be omitted). Distinguish the layers explicitly.
- **MAJ-3** — the prescribed `default:` on a non-required field reproduces a codegen bug documented in `TaskCreateRequest.yaml:121-125` (openapi-typescript emits non-optional). Must be description-only, with a generated-TS optionality test. (Also verified: all refs are external-file `$ref`s; per-parent anonymous structs; NOT the ADR-034 oneOf hazard.)
- **MAJ-4** — D7 creates an untrusted-content laundering path: the quote is by definition a verbatim copy out of the UNTRUSTED region (`core.go:1377`), then re-emitted — ultimately into a more privileged agent's prompt (PlanSupervisor wake) with the framing gone. No length bound anywhere. Needs `maxLength` + mandatory re-framing rule.
- **MAJ-5** — D4a names no execution mechanism: seam (sub-turn vs one-shot provider call), timeout (the `goalJudgeRoundTimeout` precedent and rationale, `goal_loop.go:517-530`), ordering vs the R5 admission cap (`:127-134` — compile currently precedes Admit), cancellation, cost attribution, nil-`agentInst` (`:99-101`).
- **MAJ-6** — a produce-then-veto loop: the D9 lexical vagueness veto (`goal_compile.go:459-461`) now fires on LLM-authored text; the user who receives the rejection didn't author it and has no repair path. Needs a bounded repair or explicit handling.

## OBSERVATION

OBS-2 the card currently never renders: the `queued` filter (`GoalThreadTailCards.tsx:36`) matches a state never emitted in production (`goal_triggers.go:64`; every call site uses `goalPillActive`). OBS-4 structurally: D2 moves vetting out of authoring while D1 moves weight onto judgment, and only goal scope keeps semantic vetting — the calibration benchmark becomes load-bearing on the unvetted-authoring rate too.
