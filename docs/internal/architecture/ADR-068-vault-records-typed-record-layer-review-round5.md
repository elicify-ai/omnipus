## Executive summary

Revision 5 is a large improvement in candour and a regression in accuracy. It declares a
verification standard — *"every claim about our own code below cites `file:symbol` or
`file:line` and was read at revision time"* — and then breaches it in the two decisions that
carry the most weight: **D15.0's tool count is wrong (98, not 102)**, and **D16.4's
two-index mitigation is built on a freshness token that does not exist anywhere in the
codebase**.

The D16 storage override is the fourth guess. It replaces a measured design with an unmeasured
one, and the sentence it cites as grounds is taken from the spike's own list of things it
*did not measure*. The blast-radius criterion, now load-bearing for the entire tool surface,
is applied under two mutually incompatible readings and misclassifies at least one operation
that D23.3 uses as proof it works.

**Findings: 8 CRITICAL, 25 MAJOR, 3 MINOR, 2 OBSERVATION.**

**Verdict: BLOCK.**

## 4. Unasked questions

1. **What, concretely, is the freshness token?** An integer? A content hash of the manifest? Written before or after the SQLite transaction commits? Per-index or per-note? Without an answer, C-1 cannot be closed.
2. **What happens when the bleve write succeeds and the SQLite write fails?** One note, two index updates, no transaction spanning them. Does the note get re-queued? Is the properties index marked stale wholesale? Does the next query refuse?
3. **Under a live agent writing continuously, does a whole-index freshness comparison ever return "fresh"?** If not, every answer reports `complete: false`, the problem report becomes noise, and D13's channel is trained into irrelevance — the failure D22.2 warns about, arriving from the other direction.
4. **Which store answers `status = 'prospect'`?** M-1's question. It has a one-sentence answer and the ADR does not give it.
5. **What does a record query return on a target where SQLite cannot build?** C-3. "It doesn't build" is not an answer an operator can act on.
6. **Who deletes the nine `knowledge_*` tools, and in which wave?** M-7.
7. **Does `vault_edit.create` accept a template?** M-25. `vault_describe` promises to list them.
